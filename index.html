Integrasi Database Google Sheets

Hubungkan aplikasi ini ke Google Sheets pribadi Anda agar seluruh data tersimpan secara permanen di cloud dan bisa diakses dari perangkat manapun.

Wajib deploy Apps Script milik Anda sendiri dan isi Web App URL-nya di sini. Jangan memakai URL milik orang lain, agar data keuangan Anda tidak tercampur dengan data pengguna lain di spreadsheet yang sama.

Panduan Setup Backend (Code.gs):

  1. Buka file Code.gs di projek Anda.
  2. Salin seluruh kode dari file Code.gs ke Apps Script Google Sheet Anda.
  3. Klik **Terapkan (Deploy) > Deployment Baru (New Deployment)**.
  4. Setel akses ke **Anyone (Siapa Saja)**.
  5. Salin **Web App URL** dan tempelkan pada kolom di atas!
